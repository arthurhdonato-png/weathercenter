Chave das notificações do WeatherCenter

Esta página cria a chave que assina as notificações enviadas pelo GitHub Actions. Tudo acontece só neste navegador: a chave não é enviada para lugar nenhum.

Valor do secret VAPID_PRIVATE_KEY:

Cole este valor só no GitHub (Settings → Secrets and variables → Actions → New repository secret). Não mande em chat nem e-mail.

Gere a chave uma única vez. Se trocar depois, todos os aparelhos precisam ativar os avisos de novo.
